# Changelog

All notable changes to this project are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/) and the project uses
[Semantic Versioning](https://semver.org/).

This file is the **project-wide ledger**: every `/implement` and `/verify` run (and any
manual change) appends a categorized entry via `/track`. The per-feature source of truth still
lives in `specs/NNNN-slug/` — this file is the chronological, human-readable summary on top.

## Categories
- **Added** — new features / capabilities.
- **Changed** — changes to existing behavior.
- **Fixed** — bug fixes.
- **Removed** — removed features / files.
- **Security** — vulnerabilities found/fixed, hardening, dependency CVEs.
- **Docs** — documentation, specs, or tooling-only changes.
